# 🏐 PerfMatch Frontend - Volleyball Match Prediction UI

This is the **frontend** of the PerfMatch project — an intelligent interface that allows users to:

1. 🧠 **Predict** whether a selected volleyball team will **win or lose**
2. 📊 **Visualize** each selected player’s **contribution score** (e.g., pass, assist, block)

The predictions and contributions are powered by machine learning models trained in the [backend repository](https://github.com/zgeblbl/perfmatch-ain311project).

---

## 🌐 Features

- 🧍 Select players from a dynamic list
- 🔮 Predict win/loss outcomes instantly
- 📈 View detailed player contributions
- 🚀 Communicates with a backend that runs ML models

---
## 📦 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/yourusername/perfmatch-frontend.git
cd perfmatch-frontend
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server
```bash
npm start
```
The app will run at http://localhost:3000 by default.
